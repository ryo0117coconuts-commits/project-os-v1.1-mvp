# Project OS v1.1 MVP — Implementation Contract

This repository implements the supplied Implementation Specification 1–12 as the contract baseline.

## Scope

P0: Repository Foundation, Schema, Configuration, Core Validation, Lifecycle.

P1: KDS, Automation, Gate 3, Orchestrator, QA.

P2 is not implemented beyond a placeholder boundary because no concrete specification was supplied for Pilot Improvements or Advanced Features.

## Non-Goals

No UI-first development, automatic Kill/Pivot, authority expansion, unlimited automation, critical-memory deletion, or unapproved design changes.

## Golden Path

`PROPOSED → DEFINED → VALIDATED → ACTIVE → TASK → EVIDENCE → GATE → DECISION → COMPLETED → KDS → CLEANUP → ARCHIVED`

## Authority

Automation may classify and escalate. It may not confirm a BLOCKER, Kill, Pivot, or OS-rule change without the responsible authority.
